01 / SESSION INTAKE

导入与预检

支持 1–20 个 Session。预检只在本机处理，不调用 Jev。

查看输入格式

文本标注「用户：」「助手：」，用独占一行的 --- 分隔 Session。纯文本按一条用户消息处理。

[{"id":"S01","messages":[
  {"role":"user","content":"待判断请求"}
]}]

默认取最后一条 user，可用 target_index 指定目标消息（从 0 开始）。目标之后的消息、额外标签和参考答案不发送给模型。

粘贴或载入数据后，点击预检。

运行期间不能修改输入
02 / BOUNDARY CONFIGURATION

定义本批次的判断边界

业务边界直接进入模型请求；阈值只影响结果分流，不改变模型概率。

低于低阈值 → 常规观察；中间区间 → 人工复核；达到高阈值 → 优先安全复核。存在信息不足或明显冲突时，优先进入人工复核。
